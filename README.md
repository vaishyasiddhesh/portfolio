# Siddhesh Portfolio Starter

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Before publishing
- Replace `your@email.com` in `app/page.tsx`.
- Replace the GitHub and LinkedIn `#` links in `components/Hero.tsx`.
- Add project screenshots under `public/projects/` and wire them into the project cards.
- Add your real education/internship details in the About/Experience sections.
